# Solar Dashboard – Home Assistant app

Glas-dashboard til tablet med solceller (Solplanet), batteri, timepris på strøm, VW ID.3, Tuya-enheder og vejr.

## Installation

**Hurtigst:** åbn dette link på tabletten (det åbner i Home Assistant-appen):

[![Tilføj repository til Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FbMotsen%2FHa-Dashbord-)

Eller manuelt med adressen `https://github.com/bMotsen/Ha-Dashbord-`:


1. Home Assistant → **Indstillinger → Apps → App store**
2. **⋮** (øverst til højre) → **Repositories** → indsæt adressen på dette repository → **Tilføj**
3. Genindlæs siden, find **Solar Dashboard** og tryk **Installér**
4. Udfyld **Konfiguration**, slå **Vis i sidepanel** til og tryk **Start**

Se fanen *Dokumentation* på app'en for detaljer.
